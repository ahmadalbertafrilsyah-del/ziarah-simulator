# Prompt aset multi-sisi

Gambar dibuat dengan alat pembuatan gambar bawaan, memakai gambar unggahan pengguna sebagai referensi. Tidak memakai CLI/API key pengguna. Atlas asli dipertahankan; tiap tampak dikemas menjadi PNG transparan tanpa pembesaran resolusi.

## vespa

Use case: stylized-concept. Asset type: game sprite atlas with FIVE orthographic directional views. Reference image: identity, clothing, materials and polished cartoon 3D render style. Subject: the mint teal and cream vintage Vespa scooter, tan leather saddle, cream wheel rims, chrome mirrors and rails. Empty scooter without people. Wheels straight, kickstand RETRACTED, ready to ride. Show the entire scooter consistently at the same scale.
Create ONE precisely laid out 3-column by 2-row sprite sheet, landscape 3:2 aspect, ideally 3072x2048 pixels. Each of the six cells is a square, centered isolated sprite with 12% transparent margins, no sprite touches cell boundaries. EXACT cell order: top-left FRONT view facing viewer; top-middle BACK view facing away; top-right RIGHT side view with subject facing RIGHT; bottom-left LEFT side view with subject facing LEFT; bottom-middle TOP view looking directly down, subject facing UP; bottom-right completely empty transparent. Front/back/side views viewed from a mild elevated riding-game camera angle about 12 degrees, top is true overhead. Single identical subject in each occupied cell, consistent colors, proportions and scale. High detail, clean antialiased silhouette, sharp fabric/chrome details, soft neutral baked lighting, no ground shadow. TRANSPARENT background across whole atlas, no floor, no labels, no text, no grid lines, no frame, no watermarks. This is a production sprite atlas, not a mockup.
